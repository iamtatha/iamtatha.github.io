How the numbers are worked out
  • Burst: back-to-back messages from one person, with no reply in between and each sent within the merge window set above. Three quick texts count as one burst.
  • Reply time: from the last message of one person's burst to the first message of the other person's next burst. Gaps longer than the conversation break are not counted as replies; that message starts a new conversation instead.
  • Typical reply is the median, which ignores a few very long waits. The average is shown too and is pulled up by those waits.
  • Double text: someone sends a new burst after their previous one got no reply for longer than the merge window.
  • Conversation nobody replied to: someone texted after a long silence and the other person never answered before the next break.
  • Language is judged per text message by its script (Bengali, Devanagari, Latin…). Latin-script messages are tagged Romanized Bengali or Hindi when they contain common words from those languages; this is a best guess.
  • Media, deleted messages and calls count as messages for timing but add no words. System notices (encryption, number changes, group events) are ignored.
